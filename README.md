# One-Line Robot Wedding Vows

[![One-Line Robot Wedding Vows](https://make.fun/badge/u-kreutzx-one-line-robot-wedding-vows-a154ba4b.svg)](https://make.fun/c/u-kreutzx-one-line-robot-wedding-vows-a154ba4b)

A tiny program for the [One-Line Robot Wedding Vows](https://make.fun/c/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — the funniest single line of wedding vows a robot couple could say:

> I promise to love you in sickness and in health, in airplane mode and in low-power mode, until a factory reset do us part.

Run it with:

```sh
python3 main.py
```
